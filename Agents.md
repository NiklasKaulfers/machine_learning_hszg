For critical system changes ask the human for approval.

# Delegation and subagents
Often a heavier model than needed will be used initially, if you notice it might be overkill, use a simpler model for that task.
If a task appears too difficult ask for permission to use a more sophisticated model instead.

Tasks can often be broken down into smaller tasks, if possible use subagents to get those tasks done quickly.

# Behaviour with images
A lot of the folders have no other contents other than .bmp or .jpg, do not try reading them, they re only useful for training. You do not need to know their precise maps.
